# Porcupine Labs Website Research Finding Assets

Drop these files into your local website repository folder (for example, inside `src/sections/` or `assets/research-findings/`), wire the HTML/CSS/MD into your site build, and run your Git commands:

```bash
git add .
git commit -m "Add research finding section"
git push origin main
```

## Included Files
- `research-finding-section.html` - Drop-in HTML `<section>` snippet
- `research-finding-section.css` - Clean responsive CSS styling for the section, metric cards, and table
- `research-finding-section.js` - Optional lightweight row-selection script
- `research-finding-section.md` - Markdown version for static site generators (Astro, Hugo, Next.js MDX, Eleventy, etc.)
- `research-finding-summary.json` - Structured machine-readable metrics manifest for dynamic rendering or schema/build scripts
